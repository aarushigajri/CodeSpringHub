# Using AI for bioinformatics: BSR guidance

AI assistants can help with coding, troubleshooting, interpretation and writing, but
AI-generated code or recommendations can look plausible while using unsuitable methods,
incorrect assumptions or unreliable interpretations.

## Before trusting an AI-assisted analysis
- Check that the method suits the experimental design (replicates, batches, controls).
- Read and understand generated code before running it on real data.
- Confirm reference genome and annotation versions match the data.
- Keep the code, parameters and software versions so the result is reproducible.

## When to involve BSR
- The analysis is novel, or no BSR-registered workflow matches the data.
- Results will support a publication, grant or clinical/human-subject decision.
- The AI's answer is uncertain, inconsistent across attempts, or you cannot verify it.

## Handling sensitive information
- Do not paste confidential project details or genomic data into a chat.
- Register data through CodeSpringHub so access follows existing cluster permissions.
